# Rehearse — AI Mock Interview Preparation Platform

An AI interview preparation platform designed in a warm, mid-century vintage editorial aesthetic. Rehearse provides a conversational interview experience with adaptive questioning, audio/video device checks, real-time feedback, rubric-driven scoring, and personalized learning roadmaps.

## 🌟 Key Features

- **Mid-Century Modern Editorial Design**: Built with Tailwind CSS, Instrument Serif, and DM Sans, following a distinctive retro-editorial visual language.
- **Complete 9-Stage Mock Interview Journey**:
  1. **Initiation**: Personalized preparation overview and quick role selection.
  2. **Track Selection**: Technical, Behavioral (STAR), HR & Culture, Coding, Mixed, and Custom tracks.
  3. **Configuration**: Roles, Experience (Fresher to 5+ yrs), Difficulty (including Adaptive AI), Duration, Style, and Tone.
  4. **Personalization**: PDF/DOCX resume drag-and-drop parsing and Job Description requirement alignment.
  5. **AI Interviewer Personas**: Choose between Alex, Morgan, Jordan, and Taylor with voice auditions and pace tuning.
  6. **Blueprint & Rubrics**: Pre-interview summary and "What you'll be evaluated on" checklists.
  7. **Hardware Check**: Real-time microphone input volume meters (Web Audio API), camera toggle, and speaker test chimes.
  8. **Live AI Virtual Room**: Immersive interview room with animated AI speech waveforms, webcam feed, speech/text response inputs with STAR presets, and dynamic pushback follow-ups.
  9. **Comprehensive Performance Report**: Benchmarked score / 100, competency breakdown bars, question-by-question analysis with FAANG-calibrated model answers, and printable PDF export.
- **Progress & History Dashboard**: Track average scores, performance over time, and launch focused 10-minute weak-area drills.
- **Authentication**: Fully functional sign-up, login, social OAuth simulation, and persistent user profile states.

## 🛠️ Tech Stack

- **Framework**: React 19 + TypeScript + Vite
- **Styling**: Tailwind CSS v4
- **Icons**: Lucide React
- **Animations & Effects**: Canvas Confetti, Web Audio API, Web Speech Synthesis
- **Linter**: Oxlint

## 🚀 Getting Started

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production

```
